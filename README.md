# 📸 Photography Website (Mini Project 2)

A simple and visually appealing **Photography Website** built using **HTML and CSS**. This mini-project focuses on applying fundamental web design concepts such as **color theory, typography, layout, spacing, and visual hierarchy**.

## ✨ Features

* 📷 Photography-focused landing page
* 🎨 Color wheel and color theory concepts
* ✍️ Typography and font styling
* 📐 Clean layout using HTML & CSS
* 🔗 Font Awesome icons
* 🌐 Google Fonts for typography
* 📚 MDN Web Docs used as a learning/reference resource
* 📱 Simple and responsive design approach

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome
* Google Fonts
* MDN Web Docs

## 🎯 What I Learned

Through this project, I practiced:

* Choosing and combining colors using the **color wheel**
* Using typography to improve visual appeal
* Creating structured layouts with HTML
* Styling and positioning elements with CSS
* Using external icon and font libraries
* Improving the overall visual hierarchy of a webpage

## 🚀 Purpose

This project was created as part of my **Full-Stack Development learning journey**, after completing the core HTML and CSS concepts. The goal was to strengthen my fundamentals by building another project from scratch and applying concepts learned during the course.
